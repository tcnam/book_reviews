#  Tổng quan

Báo cáo tài chính gồm **3** phần:

```md title="Balance sheet"
Vị trí: thứ nhất
Thuật ngữ tiếng việt: bảng cân đối kế toán
Các thông tin thể hiện:
  - Tài sản
  - Nợ phải trả
  - Vốn chủ sở hữu doanh nghiệp
```

```md title="Income Statement"
Vị trí: thứ hai
Thuật ngữ tiếng việt: báo cáo kết quả hoạt động kinh doanh
Các thông tin thể hiện:
  - Doanh thu
  - Chi phí
```

```md title="Cash flow statement"
Vị trí: thứ ba
Thuật ngữ tiếng việt: báo cáo lưu chuyển tiền tệ
Các thông tin thể hiện:
  - Dòng tiền đi vào doanh nghiệp
  - Dòng tiền đi ra doanh nghiệp
```
